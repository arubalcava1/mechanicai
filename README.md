# mechanicai

A lightweight, interactive chatbot prototype designed to diagnose mechanical vehicle issues. 

This project was built as a hands-on exploration into integrating Large Language Models (LLMs) with a custom web interface. It is a proof-of-concept for AI-driven troubleshooting rather than a production-grade application.

## Features

* **Vehicle Context Input:** Dedicated fields to capture vehicle details, ensuring the AI receives relevant context before offering diagnostics.
* **Chat Interface:** A responsive, structured UI designed for seamless chat interactions.
* **Local Persistence:** Utilizes `localStorage` to retain chat history across page refreshes.
* **System Guardrails:** Configured instructions designed to keep the chatbot strictly focused on mechanical and automotive diagnostics.

## Tech Stack

* **Frontend:** TypeScript, CSS, JavaScript
* **Backend:** Python (handles interface with the LLM API)

## Project Status

This is a completed hobby project. The core chat and input functionalities are operational. There are no plans for active development, feature additions, or scaling.
